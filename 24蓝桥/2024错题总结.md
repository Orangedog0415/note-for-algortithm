结合我们刚刚讨论的几道蓝桥杯题目（A题、C题、D题），我帮你把踩过的坑和易错点做个梳理。主要分为**审题界限**、**算法思维**和**代码实现**三个方面，你可以记在你的 易错整理.md 里考前多看几遍：

### 1. 审题与边界处理防坑
* **没看清终止条件（A题 日期计算）**：题目要求算到 `2024年4月13日`，但你在写多重循环时，年份跑到 2024 后，月份和日期依然完全按照原本的 `1~12` 月和满月天数跑。
  * **建议**：写日期/区间枚举题，一定要在最后一层循环里或者外层加一个 `if(y == end_y && m == end_m && d > end_d) break;` 的特判，截断越界数据。

### 2. 算法选型与思维突破
* **想得太复杂，杀鸡用牛刀（D题 树上公共前缀）**：一看到树上路径问题就想生搬硬套“树剖（树链剖分）”。但仔细看题目性质——**“对于任意结点，其儿子结点的权重互不相同”**，这个强条件意味着树上向下走的路径是唯一的，直接“变向成有根树 + 按权值排序儿子 + 双指针匹配 DFS”就能做。
* **思维僵化，遗忘基础技巧（C题 贪心/DP前缀和优化）**：面对公式里带有不等式条件的求和式（如 $c_i > x$），第一时间有点懵。
  * **建议**：看到“大于某值的全加起来”，条件反射式地想到**权值线段树**或者**后缀和/前缀和桶**。

### 3. 树的基础代码与 DFS 细节
* **建树防死循环：不懂回边 `fa` 的应用（D题）**
  * **你的原写法**：在无向图转有根树时写了 `if(v == u) continue;`。但邻接表里存的本来就不是自己，而是连通点（包含父亲）。
  * **正确做法**：DFS 时必须传一个 `fa` (父亲结点) 参数，写 `if(v == fa) continue;`，这样才能防止往回搜导致死循环。
* **找不到递归出口（D题）**
  * **误区**：总觉得递归一定要手写一堆 `if(叶子节点) return;` 这种显式的出口。
  * **真相**：在树的遍历和匹配中，**“没路线可走”本身就是天然的出口**。遍历邻居时屏蔽了 `fa`，叶子结点自然就不会进去循环直接弹栈；同理，双指针匹配时 `while` 循环因为找不到相等的权值结束，也会自动 `return`。

### 4. C++ 语言与工程小寄巧
* **容器传参没加引用 `&`**：在 `build_tree` 中，你的 `ch` 数组没有加 `&`（变成按值传递），导致建完树所有子节点全在局部变量里被销毁，主函数里拿到的全是空树。
* **全局变量顺序与大小（初始化陷阱）**：
  * **问题**：在 `n, m` 还未读入的时候，直接用它们去定义全局 `vector<int> c(n + 10)`，这会导致大小初始化错误。
  * **解决**：开局要么直接按题目数据范围最大值（如 `200010`）开全局常量长度，要么在 `main` 里面拿到 `n` 后再 `resize`。
* **复制粘贴一时爽，变量忘记改**：在 D 题中，处理第二棵树（树2大小为 $m$）的边以及给儿子排序时，你的循环边界顺手写成了 `i < n - 1` 和 `u <= n`，导致 RE 或 WA。

**总结一句话**：最近多练练**图/树的裸 DFS（记得带 `fa`）**，以及多留心变量名的 `n / m` 区分和传参引用 `&`，比赛里能帮你少丢好几十分的罚时！
